\review{AE}{The authors need to resolve remaining table cross-reference inconsistencies.}

\reply We thank the Associate Editor. The inconsistencies arose because the
previous revision added the notation table (now Table~II), which shifted the
numbering of every subsequent table by one, while five in-text table
references had been typed as fixed Roman numerals and therefore did not
update. We have corrected all five and replaced each fixed numeral with an
automatic \LaTeX{} cross-reference, so that the cited number is now generated
from the table itself and cannot drift in later edits. Table~A summarizes the
corrections; the detailed changes are given under R1.1--R1.4 and R2.1.

\begin{center}
\textbf{Table A: Summary of the corrected table cross-references.}\par\smallskip
\small
\begin{tabular}{@{}llccl@{}}
\toprule
Location & Referenced content & Previous & Revised & Raised by \\
\midrule
Section III-G, p.~8 & Validator list & Table~IV & Table~V & R1.1 \\
Section IV, p.~9 & Edge hardware & Table~II & Table~III & R1.2 \\
Section IV, p.~9 (two instances) & System configuration & Table~V & Table~VI & R1.3 \\
Section V-F, p.~12 & ONNX hashes and concordance & Table~VIII & Table~IX & R2.1 (proofreading) \\
\bottomrule

\end{center}

No experimental results, figures, tables, equations, or claims were changed
in this round; the revision is limited to the cross-references listed above.

validator set.

\mshead{III-G}{Clique Provenance and Proposed PoA$^2$ Control}

block-seal attribution.

\review{1.2}{The experimental-setup section also appears to reference Table II for the edge hardware [\ldots], whereas the relevant table is Table III.}

\reply We agree. The edge-hardware reference in Section~IV now cites
Table~III.

\review{1.3}{The experimental-setup section also appears to reference [\ldots] Table V for the overall system configuration, whereas the relevant table is Table VI.}

\reply We agree. Both references to the system-configuration table in
Section~IV (the pinned software environment and the configuration summary)
now cite Table~VI. The corrected paragraph below also contains the R1.2
correction.

\loc{Page 9: corrected edge-hardware and system-configuration references in Section IV}
\begin{excerpt}
\mshead{IV}{Experimental Setup}

Software components were developed and validated in a pinned software
environment (\textcolor{red}{Table~VI}) to fix dependency versions for
reproducibility. Edge-performance and cross-architecture determinism
experiments were then run on real hardware---an uncapped x86\_64 server
reference, an NVIDIA Jetson Orin Nano, and a Raspberry Pi~4
(\textcolor{red}{Table~III})---rather than in resource-capped containers.
\textcolor{red}{Table~VI} summarises the complete system configuration,
software stack, blockchain parameters, edge hardware, and dataset
specification.
\end{excerpt}

the tables themselves.
